# 🏗️ Architecture Mindset

I prefer architectures that keep **business logic independent, data access isolated and applications easy to evolve.**

```text
                    ┌───────────────────────┐
                    │      CLIENT / UI      │
                    │ Angular · React · Next│
                    └───────────┬───────────┘
                                │
                                ▼
                    ┌───────────────────────┐
                    │       API LAYER       │
                    │ Controllers · DTOs    │
                    │ Validation · Auth     │
                    └───────────┬───────────┘
                                │
                                ▼
                    ┌───────────────────────┐
                    │   BUSINESS / SERVICE  │
                    │ Business Rules        │
                    │ Application Logic     │
                    └───────────┬───────────┘
                                │
                                ▼
                    ┌───────────────────────┐
                    │     DATA ACCESS       │
                    │ EF Core · Dapper      │
                    │ Repositories          │
                    └───────────┬───────────┘
                                │
                                ▼
                    ┌───────────────────────┐
                    │       DATABASE        │
                    │ SQL Server · Postgres │
                    └───────────────────────┘
```

### Principles I Follow

* **SOLID**
* **Clean Code**
* **Separation of Concerns**
* **Dependency Injection**
* **Repository / Service Patterns**
* **DTO-based API Contracts**
* **Centralized Exception Handling**
* **Authentication & Authorization**
* **Database Optimization**
* **Reusable Components**
* **Modular Architecture**
